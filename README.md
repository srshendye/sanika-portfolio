# Editorial Portfolio

A responsive React + TypeScript portfolio built with Vite.

## Run locally

1. Install Node.js (LTS).
2. In this folder, run `npm install`.
3. Run `npm run dev`.
4. Open the local URL printed in the terminal.

## Personalize before publishing

Search the project for `YOUR.` and replace the placeholder contact details in `src/App.tsx`:
- `YOUR.EMAIL@example.com`
- `YOUR-LINKEDIN`
- `YOUR-GITHUB`

`public/resume.pdf` is already populated with the résumé you supplied. Replace it when you update your résumé.

Review all experience dates, education details, project descriptions, and skills before publishing. The site copy is based on the résumé you supplied.

## Build

Run `npm run build`. Vite outputs the production site to `dist/`.

## Deploy on Vercel

1. Create a GitHub repository and push this project.
2. Sign in to Vercel and choose **Add New → Project**.
3. Import the GitHub repository.
4. Keep the default Vite settings:
   - Build command: `npm run build`
   - Output directory: `dist`
5. Deploy. Vercel will provide a public URL.
6. Add a custom domain later if desired.

No environment variables are required.
